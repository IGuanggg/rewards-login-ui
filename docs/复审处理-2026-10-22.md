# 复审问题处理记录（2026-10-22）

对应 `docs/复审与审美修改建议-2026-10-22.md`。真实微软账号登录仍需在你的本机实例上完成，下面的结果来自隔离测试。

## 功能

| 问题 | 处理 | 回归 |
| --- | --- | --- |
| 8～15 位访问密码重启后失效 | 保存和读取统一为至少 8 位；已有短密码不再被静默替换 | `short_password_survives_restart` |
| 退出后的 Cookie 重启后又有效 | 会话签名材料每次启动随机生成；退出时再更换一次。未登录的退出请求返回 401，不能作废别人的会话；已有日志连接也会关闭 | `revoked_cookie_stays_dead_after_restart` |
| 缺少配置仍显示就绪 | 手动授权要求 `config.json` 且含 `sessionPath`；签到构建产物单独检查，不再和授权混成一个“就绪” | `preflight_uses_requested_path_and_requires_sessionpath` |
| 空目录被当成 Chromium | 必须找到非 headless 的浏览器可执行文件 | 代码检查 `findChromiumExecutable` |
| 指定检查 B 却返回 A | `?botDir=` 优先于当前已连接实例 | 同上回归 |
| 空 Cookie 或损坏会话判成功 | 成功还要求会话 JSON 可解析，且至少有一个带名称和值的 Cookie | `empty_or_broken_session_is_not_success` |

`node tools/acceptance.mjs`：**27 项全部通过**，明细在 `docs/acceptance-rerun.json`。

## 界面

- 账号列表成为主区域；「添加账号」在标题旁，点击后打开对话框，空状态也有同一个入口。
- 每行只保留邮箱、一行会话摘要和「连接 / 重新连接」。签到、编辑、删除收进「更多」。
- Cookie 数量、账号槽位不再出现在列表上。
- 地区和语言输入框使用 `minmax(0, 1fr)`，不再溢出重叠。
- 保存提示整句包在一个文字容器里，不再被拆开换行。
- 主按钮改为稳定的深蓝纯色，去掉永久流动动画。
- 浅色辅助文字加深；正文输入 15px，窄屏输入 16px，窄屏主操作按钮 44px。
- 列表不再套一层内部滚动。

截图已重出：`docs/shots/dashboard.png`、`add-account.png`、`mobile.png`、`dashboard-light.png`。

## 仍需你本机确认

真实的「首次微软登录 → 保存会话 → 重启面板 → 再次使用」需要你的账号、依赖和 Chromium。面板只能在弹出的浏览器里等待你完成登录，不会把密码自动填进微软页面。
